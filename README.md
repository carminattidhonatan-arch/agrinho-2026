# Agrinho 2026 - Agro Forte, Futuro Sustentável

![Agrinho Banner](https://images.unsplash.com/photo-1500937386664-56d1dfef3854?q=80&w=1600&auto=format&fit=crop)

## Sobre o Projeto

Este projeto é uma página web responsiva desenvolvida com **HTML, CSS e JavaScript** para o tema do Agrinho 2026:  

> "Agro Forte, Futuro Sustentável: equilíbrio entre produção e meio ambiente"

O objetivo é mostrar como o agronegócio pode crescer de forma sustentável, respeitando o meio ambiente e incentivando práticas responsáveis.

A página inclui:

- **Seção Hero** com destaque visual e chamada principal
- **Cards de informação** sobre sustentabilidade, tecnologia e preservação
- **Galeria de imagens** do campo e do agro
- **Seção de impacto** com contador animado de árvores preservadas simbolicamente
- **Mensagem final** reforçando o equilíbrio entre agricultura e meio ambiente
- **Menu fixo** para navegação rápida entre as seções

---

## Tecnologias Utilizadas

- **HTML5** – Estrutura do site
- **CSS3** – Estilo, layout responsivo e animações
- **JavaScript** – Contador animado na seção de impacto
